Cookie policy

This site sets no cookies. Not analytics, not advertising, not a preference cookie. That is why you have not been shown a consent banner — there is nothing to consent to.

What that means in practice

No visit to aphelioncyber.com is recorded against you. No third-party script runs on these pages except the web font stylesheet served by Google Fonts, which delivers the typefaces and sets no cookie of its own.

Local storage

The site uses your browser's session storage for one thing only: remembering, within the current tab, that you have already watched the home page hero animation, so it does not replay from the beginning on every navigation. It is discarded when you close the tab and it is never sent anywhere.

If that changes

If we ever add analytics, this page will say so before it happens, and a consent mechanism will accompany it. Write to secure@aphelioncyber.com with any question.
